Entry for the make.fun bounty **"One Line, One Minute: The Vending Machine Pickup Line Contest"** — a program that writes one pickup line a vending machine would use on a passing human, at most 200 characters, to `/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

## The line

> I know we just met, but I've been stuck on you since the day your coin got stuck in my slot.
